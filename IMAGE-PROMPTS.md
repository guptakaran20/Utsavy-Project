# Nano Banana prompts — one image per prompt, in priority order

Nano Banana makes **one image per prompt**, so every prompt below is complete on its own (style line already included). Do them in order: **A (1-10) transforms the site, B (11-20) is a nice upgrade, C is optional.** Where several small pieces share one prompt, it is a *sheet* — generate it once, then I slice it in code.

**Transparency:** it cannot output real transparency. For every **TRANSPARENT** image, generate on the pure white background the prompt asks for, then run it through remove.bg (or Photoshop "Remove background") and save as **PNG**. **OPAQUE** images save as WebP. Save everything in `public/art/` with the file name given and tell me.

Style line used in every prompt: *hand-painted gouache and silk-embroidery illustration, soft matte finish, phulkari palette (deep maroon, rose pink, marigold, saffron, sage green, ivory) with gold zari accents, no text, no letters, no watermark, no people.*
